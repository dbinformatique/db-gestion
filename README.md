# D&B Gestion

Application de gestion interne de D&B Informatique (clients, devis, factures, prospection, visites terrain), publiée sur Netlify à l'adresse `gestion.dbinformatique.cm`.

- Ce dépôt ne contient **ni donnée, ni mot de passe, ni clé** : les données restent sur l'appareil (chiffrées par le code d'accès) ou dans Firestore (protégées par la connexion et les règles).
- Toute modification passe par une branche `claude/<sujet>` et une demande de fusion ; fusionner dans `main` publie en production.
- Guide de mise en ligne : dépôt `dbinfo-documents`, `06_Applications/Integration_Gestion_Site.md`.
